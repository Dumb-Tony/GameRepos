# The Benefactors — Working Agreement

- Work only inside `the-benefactors/` unless the user explicitly requests a repository-level change.
- Do not modify `brainrot/`, `tidebound/`, `brand/`, or root game files.
- Read `docs/game-design-document.md` before implementing a milestone.

- Keep authored content separate from engine and interface code.
- Preserve stable state, evidence, location, dialogue, and deduction IDs.
- Complete one milestone at a time and keep tests passing.
