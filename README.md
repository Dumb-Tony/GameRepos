## Brainrot: Rise of the Meme

A satirical browser strategy game — infect humanity with terminal brainrot before
the world can cure itself. Pick a starting region, spend 💜 Virality on Transmission,
Symptoms & Abilities (every upgrade is a tradeoff), and outpace 🧪 The Cure.

**Ride the wave:** 🔥 **Trend Heat** is viral momentum — it spikes on viral moments
(new regions catching on, tapped bubbles, world events, fresh evolutions) and decays
fast. While you're hot, your income surges and the rot spreads faster — but the world
is watching, so The Cure researches harder. Build heat, ride it to spread, then lie
low before it burns you. Play across four difficulties, including 🎲 **Chaos**, where
events and mutations fire nonstop.

Runs from the modular sources in [`brainrot/`](brainrot/) with no build step or
dependencies — just open `brainrot/index.html` in a browser. (`brainrot/build.js`
can bundle it into a single self-contained file for sharing.)
