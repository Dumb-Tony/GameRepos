## Brainrot: Rise of the Meme

A satirical browser strategy game — infect humanity with terminal brainrot before
the world can cure itself. Pick a starting region, spend 💜 Virality on Transmission,
Symptoms & Abilities (every upgrade is a tradeoff), and outpace 🧪 The Cure.

Each game is a single self-contained `index.html` (no build step, no dependencies) —
just open it in a browser.
